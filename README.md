# AES_FPGA

**AES Encryption Demo with FPGA Acceleration**

This repository contains the final Python and C code for an educational platform that demonstrates AES-128 encryption with optional hardware acceleration using the PYNQ-Z2 FPGA board. The senior capstone project illustrates how plaintext can be encrypted via both software and hardware paths, enabling real-time comparison of performance. It supports communication between a browser-based frontend and the FPGA backend via a REST API. Code is modular, well-documented, and intended for educational use only.

**Features**:

* 🔁 AES-128 encryption via Python and custom C firmware
* ⚡ Hardware acceleration using PYNQ-Z2 (Zynq-7000 SoC)
* 🌐 REST API for data transfer between frontend and backend
* 📊 Real-time performance comparison between software and hardware encryption
* 🎓 Educationally oriented with a focus on clarity and correctness

**Languages**: Python, C

**Board**: PYNQ-Z2 FPGA

**Use Case**: Cryptography education, hardware/software co-design, embedded systems learning
